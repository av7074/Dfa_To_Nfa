THEORY
Finite Automata Concepts
What is a DFA?
A Deterministic Finite Automaton has exactly one possible next state for every state and input symbol.
M = (Q, Σ, δ, q₀, F)
What is an NFA?
An NFA may have zero, one, or multiple possible next states for an input symbol. It may also support ε-transitions, although this conversion does not need them.
N = (Q, Σ, δN, q₀, F)
Key Observation
Every DFA is already an NFA. Therefore DFA → NFA conversion is direct and does not require subset construction.
δN(q,a) = {δ(q,a)}

PROJECT REPORT
Documentation
Problem Statement
Develop an interactive simulator that accepts a DFA and constructs an equivalent NFA while allowing the user to visualize and validate both automata.
Objectives
  • Represent a DFA formally.
  • Perform direct DFA→NFA conversion.
  • Visualize states and transitions.
  • Simulate input strings step-by-step.
  • Automatically verify equivalence.
Algorithm
  1. Read Q, Σ, q₀ and F.
  2. Copy Q, Σ, q₀ and F to the NFA.
  3. For every δ(q,a)=p, store {p}.
  4. Return the constructed NFA.
Complexity
For a DFA with |Q| states and |Σ| symbols, the conversion processes |Q|×|Σ| transitions.
Time: O(|Q||Σ|)   Space: O(|Q||Σ|)
Applications
Compiler design, lexical analysis, pattern matching, protocol verification, model checking and theoretical computation.
Advantages & Limitations
Advantages: simple, fast, visual and easy to verify. Limitation: this direct conversion does not demonstrate ε-NFA or NFA→DFA subset construction.
Conclusion
The simulator demonstrates that a DFA can be represented directly as an equivalent NFA by replacing every single destination state with a one-element set. The same input language is therefore preserved.
